# File di terzi nel repository

Il codice di questo repository è proprietario ([LICENSE](LICENSE)). I file
qui sotto non sono nostri: sono copiati nel repository e restano sotto la
loro licenza. Le dipendenze installate da npm (`node_modules`) non stanno
nel repository e portano ciascuna la propria licenza.

| File | Cosa | Autore | Licenza |
|---|---|---|---|
| `public/fonts/playfair-display-latin-700-normal.woff2` | Il carattere Playfair Display, peso 700, sottoinsieme latino | The Playfair Display Project Authors | SIL Open Font License 1.1, testo in `public/fonts/OFL.txt` |

Chi aggiunge un file di terzi (un carattere, una libreria copiata, un'immagine)
aggiunge qui la sua riga, con la licenza accanto al file: lo controlla
`tests/proprieta.test.js`.
